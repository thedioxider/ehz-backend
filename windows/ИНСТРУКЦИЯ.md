# Установка ehz-backend

**Требования:** Docker Desktop.

Щёлкните правой кнопкой мыши по `setup.ps1` → **Выполнить с помощью PowerShell**.

После запуска откройте панель управления в браузере: <http://localhost:19080>

На странице отображается API-ключ — введите его в приложении при первом подключении.

Для остановки закройте окно PowerShell.

## Резервная копия

```powershell
.\tools\backup.ps1
```

Архив сохраняется в папку `data\`.

## Восстановление

```powershell
.\tools\restore.ps1 ehz-backup-20260428-120000.tar.gz
```

## Сброс данных

Удаляет все данные (база данных, фотографии, учётные данные). Перед удалением автоматически создаётся резервная копия.

```powershell
.\tools\reset.ps1
```

## Обновление

Распакуйте новый архив в ту же папку (с заменой файлов) и снова запустите `setup.ps1`.
