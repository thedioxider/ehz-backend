# Установка ehz-backend

**Требования:** Docker и Docker Compose.

## Linux

Откройте терминал в папке с архивом и выполните:

```sh
sh setup.sh
```

## Windows

Щёлкните правой кнопкой мыши по `setup.ps1` → **Выполнить с помощью PowerShell**.

---

После запуска откройте панель управления в браузере: <http://localhost:19080>

На странице отображается API-ключ — введите его в приложении при первом подключении.

Для остановки закройте терминал.

## Резервная копия

```sh
sh data/backup.sh
```

На Windows: `.\data\backup.ps1`

Архив сохраняется в папку `data/` рядом со скриптами.

## Восстановление

```sh
sh data/restore.sh ehz-backup-20260428-120000.tar.gz
```

На Windows: `.\data\restore.ps1 ehz-backup-20260428-120000.tar.gz`

## Обновление

Распакуйте новый архив в ту же папку (с заменой файлов) и снова запустите скрипт установки.
