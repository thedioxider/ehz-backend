# Установка ehz-backend

## Установка Docker

Если Docker ещё не установлен, выполните в терминале:

```sh
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER
```

После этого выйдите из системы и войдите снова, чтобы изменения вступили в силу.

Проверьте установку:

```sh
docker --version && docker compose version
```

### Если сайт docker.com недоступен

Установите Docker Engine из репозитория дистрибутива, а Docker Compose — с GitHub:

```sh
sudo apt-get update && sudo apt-get install -y docker.io
sudo systemctl enable --now docker
sudo usermod -aG docker $USER

sudo mkdir -p /usr/local/lib/docker/cli-plugins
sudo curl -L https://github.com/docker/compose/releases/latest/download/docker-compose-linux-x86_64 \
  -o /usr/local/lib/docker/cli-plugins/docker-compose
sudo chmod +x /usr/local/lib/docker/cli-plugins/docker-compose
```

После этого выйдите из системы и войдите снова, затем проверьте:

```sh
docker --version && docker compose version
```

---

Откройте терминал в папке с архивом и выполните:

```sh
sh setup.sh
```

После запуска откройте панель управления в браузере: <http://localhost:19080>

На странице отображается API-ключ — введите его в приложении при первом подключении.

Для остановки закройте терминал.

## Резервная копия

```sh
sh tools/backup.sh
```

Архив сохраняется в папку `data/`.

## Восстановление

```sh
sh tools/restore.sh ehz-backup-20260428-120000.tar.gz
```

## Сброс данных

Удаляет все данные (база данных, фотографии, учётные данные). Перед удалением автоматически создаётся резервная копия.

```sh
sh tools/reset.sh
```

## Обновление

Распакуйте новый архив в ту же папку (с заменой файлов) и снова запустите `setup.sh`.
